About naoko_http

A small web server with a clear job.

What it is

naoko_http is a webserver designed from scratch. It receives HTTP requests and answers them with static files.

It currently supports a miniature version of HTTP/1.1 only.

Who wrote it

I am Abhiyan Regmi, and I made this server.

More about the author

Written with Beej’s Guide as the reference

naoko_http is written with reference to Beej’s Guide to Network Programming, the widely read guide to socket programming. The server is built on that foundation rather than on a ready-made HTTP library.

The server is intentionally small. See Features for exactly what is and is not supported.

naoko_http was written by Abhiyan Regmi.
