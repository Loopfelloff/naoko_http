Features

What naoko_http handles today, and what it leaves alone.

Supported

  • A miniature version of HTTP/1.1
  • GET requests
  • Serving static files

Not supported

  • HTTP versions other than the miniature HTTP/1.1
  • Any request method other than GET
  • Anything beyond static files
naoko_http is under active development by its author, so this list describes the server as it is now.
