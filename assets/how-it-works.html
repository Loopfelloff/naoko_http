How a request is served

The general shape of a static file server, from request to response.

  1. A client connects and sends a request. A browser asks for a file with a GET request.

  2. The server reads the request. naoko_http understands the miniature HTTP/1.1 it supports.

  3. The server finds the file. Because only static files are served, the requested path points at a file on disk.

  4. The server sends the file back. The client receives the contents and displays them.

An example exchange

This is an illustrative example of HTTP/1.1 messages, not captured output from naoko_http.
# request from the client

# response from the server
