naoko_http

A web server written from scratch by Abhiyan Regmi. It answers GET requests with static files, using a miniature version of HTTP/1.1.

  • Miniature HTTP/1.1
  • GET only
  • Static files only
See what it does View on GitHub

I serve static files. Send me a GET request and I will fetch it!

Built from the ground up

naoko_http is not a wrapper around an existing server. It is a web server designed from scratch, written with Beej’s Guide to Network Programming as its reference.

Read the full story

Scope

GET requests and static files. Nothing else, on purpose.

Protocol

A miniature version of HTTP/1.1.

Methods

Only GET is handled.

Content

Static files are served as they are.
